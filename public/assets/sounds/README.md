# Sounds

These `.wav` files are quiet placeholders. To use a real sound, drop a file here with the **same name**
as `.mp3`, `.ogg` or `.m4a` (for example `mine.mp3`). The game uses it instead of the placeholder automatically.

| File name | When it plays |
|---|---|
| click | Tapping buttons |
| mine | Each ore you mine |
| smith | Each bar or item you smith |
| levelup | Gaining a level |
| equip | Equipping gear |
| deposit | Moving items to the bank |
| error | Something can't be done |
| welcome | The "welcome back" summary |
| music_town | Background music in Pocketvale (loops) |
