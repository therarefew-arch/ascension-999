# Sounds

These `.wav` files are quiet placeholders. To use a real sound, drop a file here with the **same name**
as `.mp3`, `.ogg` or `.m4a` (for example `mine.mp3`). The game uses it instead of the placeholder automatically.

| File name | When it plays |
|---|---|
| click | Tapping buttons |
| mine | Each ore you mine |
| smith | Each bar or item you smith |
| levelup | Gaining a level |
| equip | Equipping gear |
| deposit | Moving items to the bank |
| error | Something can't be done |
| welcome | The "welcome back" summary |
| chop | Each log you chop |
| splash | Each fish you catch |
| sizzle | Each food you cook |
| crackle | Each log you burn |
| craft | Each tool you craft or upgrade |
| enchant | A successful enhance |
| fail | An enhance that didn't take |
| hit | You attack in combat |
| hurt | A monster attacks you |
| tile | Tapping a Mahjong tile (soft wooden thud) |
| match | Finding a Mahjong match |
| anvil | Every hammer swing in Smithing (and the Enhancing hammer) |
| pickaxe | Every pickaxe swing in Mining |
| timber | The tree falling on the 5th chop |
| kindle | Snapping a twig each kindling tap |
| ignite | The fire catching ("whoomp") |
| reel | Reel ratchet — loops while you hold the reel button |
| carve | Knife carving in Crafting |
| rune | Magic chime for each Rune Trace point (plays as rising notes) |
| whoosh | A soft swish for a miss (never harsh) |
| douse | Water hissing on fire in Wildfire |
| coin | Selling, buying, request rewards |
| shing | Charging a combat strike |
| block | Raising your shield |
| eat | Eating food |
| fire_loop | Cozy fire crackle in the kitchen while the fire burns (loops) |
| music_mahjong | Calm lofi music while playing Sort the Catch (Fishing) (loops) |
| music_town | Background music in Pocketvale (loops, ~2 min) |
| music_ironmoor | Ironmoor's theme: a miners' work song with pickaxe tinks and a whistled tune (loops) |
| music_lunaria | Saved for Lunaria: deep, slow and foggy, with distant chimes (loops) |
| music_kitchen | Pantry Prep (Cooking): cosy café tune with a bubbling pot (loops) |
| music_coalhaven | Coalhaven's theme: harbour waltz, a far-off foghorn, and only two waves per loop — one long roll up the shingle (~0:10) and a few small laps against the pier (~0:48). Owner found constant waves annoying. |
