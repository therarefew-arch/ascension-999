# Pocketvale

A cozy medieval idle skilling RPG for phones. See `docs/design.md` for the full vision and `CLAUDE.md` for the project rules.

## Play on this computer
```
npm install
npm run dev
```
Then open the "Local" address it prints. To play on a phone on the same Wi-Fi, open the "Network" address on the phone.

## Phase 1
Mining and Smithing in Pocketvale, inventory, bank with search, gear with item comparison,
one idle slot with offline progress (up to 24h), auto-save, and a sound system with volume sliders.
